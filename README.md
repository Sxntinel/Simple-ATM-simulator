# Simple ATM System in C# 🏧

A console-based ATM (Automated Teller Machine) application built using C# to simulate core banking features.

## Features 🚀
* Account balance inquiries
* Cash withdrawals and deposits
* Secure PIN verification (simulation)
* Simple console menu interface

## Technologies Used 💻
* C# (.NET)
* Visual Studio / Terminal
